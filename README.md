# React Calculator App

A simple and interactive calculator built using React.js to perform basic arithmetic operations.

## Features
- Basic arithmetic operations
- Interactive user interface
- Responsive layout

## Technologies Used
- React.js
- JavaScript
- HTML
- CSS

## How to Run
1. Clone this repository.
2. Run `npm install`.
3. Run `npm run dev`.
4. Open the local URL displayed in your terminal.
